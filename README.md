# Memory Matrix

A pattern of tiles lights up on a grid for a moment, then disappears - click it
back from memory. Levels grow the tile count and eventually the grid itself
(3x3 -> 4x4 -> 5x5). Three lives, best level saved in localStorage.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/memory-matrix/

Pure client-side HTML/CSS/JS.
